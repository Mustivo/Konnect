# Konnect web (Next.js + TypeScript)

## Run
    npm install
    npm run dev        # http://localhost:3000

## Before it looks like the design
1. Export the hero photo and save it as `public/hero.jpg`.
2. (Optional) Add your logo to `public/` and use it in `components/Logo.tsx`.

## Light / dark
The page follows the visitor's system theme (both versions of your design are built in).
Colours live in CSS variables at the top of `app/globals.css`.

## Deploy
Push to GitHub, import the repo in Vercel, set Root Directory to `web`
(or whatever you name this folder) and deploy.
